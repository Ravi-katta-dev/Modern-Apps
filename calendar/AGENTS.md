## Overview
**Purpose:** Fully offline Material You calendar — works with on-device calendars, no account; acts as the system calendar so dates/events from other apps open here.
**Key features:**
- Month/pager/agenda views, event CRUD with recurrence (`RRule`), timezones, per-calendar colors
- `.ics` import (files shared from anywhere) + export; holiday calendars via generated data (`scripts/calendar`)
- Exact-alarm reminders rescheduled after reboot (`ReminderScheduler` + `BootReceiver`)
- Self-refreshing Glance widgets (agenda + month); assistant read/add via `intents/`
**Architecture / data-flow:** `ui/` screens + `ui/dialogs/` editors → `util/CalendarViewModel` (+ `CalendarUiContract`) → `data/` models (`Calendar`/`Event`/`Instance`/`ReminderMirror`); reminders flow ViewModel → `ReminderScheduler` → `ReminderReceiver` → notification, re-armed on boot.
**Entry points + reading order:** `MainActivity.kt` → `ui/CalendarScreen.kt` → `util/CalendarViewModel.kt` → `data/Event.kt` + `data/Instance.kt` → `util/RRule.kt` → `util/ReminderScheduler.kt`.
**Gotchas:**
- `util/` is NOT a closed package root — the `util/`→closed-roots migration is pending; don't add more files there
- Holiday data is generated by `scripts/calendar`, not hand-written — regenerate, don't edit
- Reminder alarms must be re-registered on boot; test the `BootReceiver` path, not just in-app scheduling
