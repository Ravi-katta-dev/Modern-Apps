A calm, fast home screen for Android TV and Google TV

Features:
- Your apps as large 16:9 banners, six per row, with nothing else competing
- HDMI inputs, Play Store and Settings one D-pad press away on the bottom row
- Giant clock and date header with a live network status icon
- Reorder, replace or remove tiles with the remote; order survives restarts
- Can be set as the default home screen via the system Home role
